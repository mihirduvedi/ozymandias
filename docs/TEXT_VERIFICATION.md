# Poem text

Ozymandias follows the fourteen-line Academy of American Poets edition at
https://poets.org/poem/ozymandias. Its text was transcribed from the source on
October 7, 2026. Spelling, capitalization, quotes, punctuation, and the spaces
in the ellipsis are preserved. In particular, the source spelling “traveller”
remains in the poem even though the interface uses American English.

The source is stored in `src/content/ozymandias.json`. Its SHA-256 is
`a0ac72fca670f48b677aa34e81d6ab5d84a700ae41b57ba377247dd37747ee8b`.
The release check verifies this file so publication cannot silently alter it.
