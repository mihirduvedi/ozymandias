# Ozymandias

## Elevator pitch

Walk through Shelley's Ozymandias in a 3D desert. Explore the ruined colossus freely, or follow a guided reading that reveals the poem line by line.

## About the project

Copy [PROJECT_STORY.md](PROJECT_STORY.md) into the About the project field. It contains the complete story without the other form fields.

## Built with

React, TypeScript, Three.js, Vite, WebGL, Web Audio, HTML, CSS, Python, FFmpeg, Vitest, GitHub Pages
